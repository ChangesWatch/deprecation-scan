# Security policy

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/ChangesWatch/deprecation-scan/security/advisories/new). Do not include credentials, private repository contents, full lockfiles, or customer identifiers in public Issues.

Supported releases: the latest `v1` release receives security fixes. The beta Action requires only `contents: read`; it never needs a write token, pull-request token, or secret.

We aim to acknowledge reports within seven days. Please include a minimal reproducible case and the expected security impact.
